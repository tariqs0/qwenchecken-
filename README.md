# نظام إدارة الدواجن المتكامل - Poultry Management System

نظام متكامل لإدارة ومتابعة مشاريع تربية الدواجن بأنواعها المختلفة (الدجاج، السمان، البط، الوز، الرومي، والدواجن النادرة).

## المميزات الرئيسية

### 1. إدارة الدفعات
- تتبع كل دفعة من البيض حتى البيع/الذبح
- حساب العمر بالأيام تلقائياً
- تحديد المرحلة (بيض، كتاكيت، نامية، بالغة)
- تنبيهات للمراحل الحرجة

### 2. الحاضنات والفقاصات
- إدارة متعددة للحاضنات
- تتبع السعة والدورات
- أنواع مختلفة (يدوي، أوتوماتيك)
- تنبيهات لفحص البيض (اليوم 7 للسمان)
- تحذيرات لعدم فتح الفقاصة آخر 3 أيام

### 3. المحاسبة والمصاريف
- تتبع جميع المصاريف (علف، ماء، كهرباء، أدوية، معدات، صيانة)
- حساب الأرباح والخسائر
- نسبة الربح لكل نوع وإجمالي
- رأس المال وصافي الربح

### 4. الإحصائيات والتقارير
- توزيع الطيور حسب النوع
- ملخص الأداء المالي
- رسوم بيانية تفاعلية

### 5. أنواع الدواجن المدعومة
- **السمان**: تكساس، بلدي
- **الدجاج**: لحم (فروج)، بياض، بلدي
- **الماء**: بط، وز
- **أخرى**: رومي
- إمكانية إضافة أنواع نادرة جديدة

### 6. معلومات تفصيلية لكل نوع
- فترة الحياة الكاملة
- فترة التفقيس
- درجات الحرارة المثلى لكل مرحلة
- الرطوبة المناسبة
- متطلبات العلف (نوع، بروتين، كمية)
- أسعار مقترحة (بيضة، كتكوت، نامي، بالغ، زوج، مجموعة)

## التركيب والتشغيل

### المتطلبات
- Node.js 16+
- متصفح حديث (Chrome, Firefox, Edge)

### تشغيل الباكند (Backend)

```bash
cd backend
npm install
npm start
```

السيرفر سيعمل على: `http://localhost:3000`

### تشغيل الفرونتند (Frontend)

افتح ملف `frontend/index.html` في أي متصفح حديث، أو استخدم سيرفر محلي:

```bash
cd frontend
python3 -m http.server 8080
```

ثم افتح: `http://localhost:8080`

## APIs المتاحة

### الدفعات (Batches)
- `GET /api/batches` - جلب جميع الدفعات
- `POST /api/batches` - إضافة دفعة جديدة
- `PUT /api/batches/:id` - تحديث دفعة
- `DELETE /api/batches/:id` - حذف دفعة

### الحاضنات (Incubators)
- `GET /api/incubators` - جلب جميع الحاضنات
- `POST /api/incubators` - إضافة حاضنة جديدة
- `PUT /api/incubators/:id` - تحديث حاضنة
- `DELETE /api/incubators/:id` - حذف حاضنة

### المصاريف (Expenses)
- `GET /api/expenses` - جلب جميع المصاريف
- `POST /api/expenses` - إضافة مصروف جديد
- `PUT /api/expenses/:id` - تحديث مصروف
- `DELETE /api/expenses/:id` - حذف مصروف

### أنواع الدواجن (Poultry Types)
- `GET /api/poultry-types` - جلب جميع الأنواع
- `POST /api/poultry-types` - إضافة نوع جديد

### الإحصائيات (Statistics)
- `GET /api/statistics` - جلب إحصائيات شاملة

### الإعدادات (Settings)
- `GET /api/settings` - جلب الإعدادات
- `PUT /api/settings` - تحديث الإعدادات

## الميزات الذكية

### 1. التنبيهات التلقائية
- فحص البيض المخصب (اليوم 7 للسمان)
- عدم فتح الفقاصة آخر 3 أيام من التفقيس
- اقتراب نهاية الدورة
- نقص الأعداد بشكل غير طبيعي

### 2. حسابات تلقائية
- عمر الدفعة بالأيام
- المرحلة الحالية بناءً على العمر والنوع
- إجمالي المصاريف والإيرادات
- صافي الربح ونسبة الربح

### 3. توصيات الأسعار
- أسعار مقترحة للشراء
- أسعار مقترحة للبيع حسب العمر
- أسعار للبيض، الكتاكيت، الطيور النامية، البالغة
- أسعار للأزواج والمجموعات

### 4. Dark/Light Mode
- دعم الوضع الداكن والفاتح
- حفظ التفضيل في localStorage
- تبديل سهل بضغطة زر
