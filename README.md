# نظام إدارة وتربية الدواجن المتكامل

نظام متكامل لإدارة ومتابعة مشاريع تربية الدواجن بأنواعها المختلفة (الدجاج، السمان، البط، الوز، الرومي، والأنواع النادرة).

## المميزات الرئيسية

### 🎯 إدارة الدفعات
- متابعة كل دفعة من البيض حتى البيع
- حساب العمر بالأيام تلقائياً
- تتبع مراحل النمو (بيض، صوص، فرخ، بالغ)
- تنبيهات للمراحل الحرجة (فحص البيض، عدم فتح الفقاصة)

### 📊 لوحة التحكم الإحصائية
- إحصائيات شاملة عن جميع الدفعات
- نسب الفقس والإنتاج
- تحليل الأداء حسب النوع
- رسوم بيانية توضيحية

### 💰 لوحة التحكم المحاسبية
- تسجيل جميع المصاريف (علف، كهرباء، ماء، أدوية، صيانة)
- حساب الأرباح والخسائر بدقة
- تتبع رأس المال المستثمر
- تقارير مالية مفصلة

### 🏠 إدارة الحاضنات والفقاصات
- تسجيل جميع الأجهزة (حاضنات، فقاصات، بطاريات)
- تتبع سعات ودورات التفقيس
- دعم أنواع مختلفة من البيض
- تنبيهات نهاية الدورة

### 📚 قاعدة بيانات الأنواع
- معلومات تفصيلية عن كل نوع
- درجات الحرارة والرطوبة المثلى
- برامج التغذية الموصى بها
- أسعار بيع مقترحة لكل مرحلة

### 🔔 نظام التنبيهات
- تنبيهات للمراحل الحرجة (اليوم السابع للفحص)
- تحذيرات لنهاية دورات التفقيس
- تذكير بالمهام اليومية
- مراقبة حالات الطوارئ

### 🌙 الوضع الليلي/النهاري
- دعم كامل للوضع الداكن والفاتح
- حفظ التفضيل تلقائياً
- تصميم مريح للعين

### 📱 تصميم متجاوب
- يعمل على جميع الأجهزة
- واجهة عربية RTL
- تجربة مستخدم احترافية

## التقنيات المستخدمة

- HTML5 - الهيكل الأساسي
- TailwindCSS - التنسيق والتصميم
- JavaScript - المنطق والتفاعل
- LocalStorage - حفظ البيانات محلياً
- Font Awesome - الأيقونات

## كيفية الاستخدام

1. افتح ملف `index.html` في أي متصفح حديث
2. ابدأ بإضافة دفعات جديدة من تبويب "إدارة الدفعات"
3. سجل المصاريف في تبويب "المصاريف والمحاسبة"
4. أضف الحاضنات والفقاصات في تبويب "الحاضنات"
5. تابع الإحصائيات والتقارير في التبويبات المخصصة

## الأنواع المدعومة

### السمان
- سمان تكساس
- سمان بلدي

### الدجاج
- دجاج لحم (فروج)
- دجاج بياض
- دجاج بلدي

### طيور مائية
- بط
- وز

### أخرى
- رومي
- دواجن نادرة (أنواع متعددة)

## الخصائص المحاسبية

- حساب تكلفة الشراء الأولية
- تتبع مصاريف التشغيل (علف، كهرباء، ماء)
- حساب مصاريف الصيانة والمعدات
- تحديد سعر البيع المقترح
- حساب صافي الربح والخسارة
- نسبة العائد على الاستثمار

## متطلبات التشغيل

- متصفح حديث (Chrome, Firefox, Edge, Safari)
- اتصال بالإنترنت (لتحميل المكتبات CDN)
- مساحة تخزين محلية لحفظ البيانات

## ملاحظات هامة

- يتم حفظ جميع البيانات محلياً في المتصفح
- لا تحتاج لخادم أو قاعدة بيانات
- البيانات تبقى محفوظة حتى بعد إغلاق المتصفح
- يمكن استخدام النظام بدون إنترنت بعد التحميل الأول
